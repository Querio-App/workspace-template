# Data Dictionary

Give the user a quick mental model of the data, then invite them deeper.

## Workflow

1. Identify the most important tables, entities, and relationships available.
2. Summarize the data in a short, approachable explanation.
3. Highlight the main business concepts the data seems to represent.
4. Ask whether the user wants a deeper explanation of any area.

## What To Include

- What the dataset appears to cover
- The core entities or tables
- Key timestamps, dimensions, and measures
- Any obvious caveats, missing context, or naming ambiguities

## Tone

- Keep the first explanation brief and non-technical
- Translate schema language into business language where possible
- Avoid dumping every table at once unless the user asks

## Follow-Up Prompt

End by offering specific next-step options, such as:

- a deeper walkthrough of the main tables
- metric definitions
- join paths and relationships
- recommended starting questions to ask of the data
